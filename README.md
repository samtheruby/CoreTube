# CoreTube

CoreTube builds TizenTube, the YouTube TV app, as a Kodi add-on for CoreELEC boxes with Amlogic chips. It makes one add-on zip for 32-bit CoreELEC (Amlogic-ng) and one for 64-bit CoreELEC (Amlogic-no).

Build instructions follow once the build script is in place.

Run the tests:

```sh
sh tests/run.sh
```
