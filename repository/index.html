Install in Kodi

  1. Open Settings → File manager → Add source and enter https://samtheruby.github.io/CoreTube/. Name it CoreTube.
  2. Open Add-ons → Install from zip file → CoreTube and choose the repository ZIP. Enable Unknown sources in Kodi's add-on settings if prompted.
  3. Choose Install from repository → CoreTube Repository → Video add-ons → CoreTube.

Kodi selects the matching package for 32-bit CoreELEC 21 or 64-bit CoreELEC 22. Install only on these supported systems. Leave automatic updates enabled to get new stable releases.

Already installed CoreTube from a ZIP? Open its add-on information, choose Versions, and select the version from CoreTube Repository to receive repository updates. Your settings stay in place.
